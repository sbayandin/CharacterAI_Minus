# CharacterAI_Minus
CharacterAI Minus is a very simple browser plugin written in JS. It removes ads, blocks "View ad to continue," and turns "Rewind" into "Super Rewind."

Super Rewind: does the same as regular Rewind, but takes the second-to-last message in the chat (usually the user's message) and inserts it into the text field. This is a kind of swipe limit bypass: unfortunately, it won't save your swipes, but it will help you delete and send messages faster.
